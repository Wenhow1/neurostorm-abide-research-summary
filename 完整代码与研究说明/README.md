## 与根目录简洁版的区别

根目录四个代码文件是少文件的架构阅读集；本目录按原模块分开，包含更多训练、调度、评估与历史设计。两者来源一致，不是两套新算法。这里“完整”指列出的源模块和函数完整，不表示已经公开全部服务器工程、数据、权重、CUDA环境或历史私人备份。

Mamba核心算子依赖mamba_ssm，Transformer注意力依赖PyTorch；外部依赖必须另行满足。历史脚本若直接运行可能写文件或占用GPU，公开代码用于阅读，不要在不核对路径与环境时直接运行。

## 状态与公开范围

主题01至11已有结果，其中不同阶段的数据协议不同。主题12残差相关目标仍在进行中，不存在最终成绩。旧源码与旧导航可能保留当时的状态或本地路径，应以当前根目录最新结果及本目录主题导航为准。

仅补充代码和研究解释，不发布原始FC、受试者名单、逐人标签/预测/特征、模型权重、原始训练日志或服务器备份；这些不随公开仓库同步。已有简洁压缩包不改成复杂大包。
